# IndustrialTwin feedback

Report bugs, request features and download releases of [IndustrialTwin](https://industrialtwin.app), the desktop app for point clouds, meshes and BIM.

- **Found a bug?** [Open a bug report](https://github.com/industrialtwin/feedback/issues/new?template=bug-report.yml)
- **Missing a tool or format?** [Request a feature](https://github.com/industrialtwin/feedback/issues/new?template=feature-request.yml)
- **Question or workflow idea?** [Start a discussion](https://github.com/industrialtwin/feedback/discussions)
- **Download:** [Latest release](https://github.com/industrialtwin/feedback/releases/latest)

The app source is not in this repository.

Contact: hello@industrialtwin.app
